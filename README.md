# 📊 Sistema de Administração de Empresas

Este é um projeto de um sistema administrativo web com autenticação (login) e um painel principal (dashboard) para gerenciamento empresarial. O projeto foi desenvolvido com foco estritamente **educacional**, com o objetivo de praticar a integração entre back-end (PHP e MySQL) e front-end (Tailwind CSS), além de aplicar conceitos de segurança, sessões e arquitetura de banco de dados.

---

## 🚀 Funcionalidades

* **Sistema de Autenticação:** Login seguro com validação e controle de sessão (`session_start` do PHP).
* **Painel Administrativo (Dashboard):** Tela principal responsiva para visualização e controle de dados da empresa.
* **Controle de Acesso:** Proteção de rotas, garantindo que apenas usuários autenticados acessem o painel.
* **Interface Moderna:** Design limpo, intuitivo e totalmente responsivo construído com Tailwind CSS.
* **Integração com Banco de Dados:** Operações de consulta e manipulação de dados utilizando MySQL de forma segura.

---

## 🛠️ Tecnologias Utilizadas

O projeto foi construído utilizando as seguintes ferramentas:

* **PHP:** Responsável pela lógica do back-end, controle de sessões e conexão com o banco de dados.
* **MySQL:** Sistema de gerenciamento de banco de dados relacional para armazenamento de usuários e informações administrativas.
* **Tailwind CSS:** Framework utilitário para a estilização rápida e responsiva do front-end.
* **HTML5 & JavaScript:** Estruturação das páginas e pequenas interações no lado do cliente.
* **Google Gemini:** Criar o design com Tailwind CSS com base no código feito em PHP.
* **Open AI ChatGPT:** Design da página de login com Tailwind CSS.
